# CS-300

In these projects, I worked on storing and organizing course data in a way that made it easy to search and display. In Project One, I compared different data structures to see which one would work best. In Project Two, I created a program that loads course information and prints the courses in alphanumeric order.

I solved the problem by looking at the advantages and disadvantages of vectors, hash tables, and binary search trees. Learning about data structures is important because they affect how fast a program can find, store, and sort data. After comparing the options, I chose a binary search tree because it allows data to stay organized and makes searching efficient.

One challenge I faced was getting the course data file to load correctly and making sure the courses displayed in the right order. I overcame these problems by testing my code, checking for errors, and making changes until the program worked as expected.

These projects changed the way I think about designing software. I learned that it is important to choose the right data structure before writing code because it can improve the program's performance and make it easier to manage.

My work in this course also helped me write better code. I learned to organize my program into smaller parts, use clear variable names, and write code that is easier to read and update. This will help me create programs that are more maintainable and adaptable in the future.
